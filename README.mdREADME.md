# E-Commerce Sales & Customer Insights Dashboard

## Project Overview
An interactive E-Commerce Sales and Customer Insights Dashboard developed using Excel, PostgreSQL and Power BI. This project analyzes online retail transactions to identify sales trends, customer purchasing behaviour, product performance and customer segments.

## Tools & Technologies
- Excel – Data cleaning and preparation
- PostgreSQL – Data storage and SQL analysis
- Power BI – Data visualization and interactive dashboards
- DAX – Calculated columns and measures

## Key Features
- Total Revenue, Total Orders, Total Customers and Average Order Value
- Monthly Revenue Trend Analysis
- Revenue Analysis by Country
- Top 10 Products by Revenue
- Customer Segmentation using RFM Analysis
- Top 10 Customers by Revenue
- Monthly New Customer Acquisition
- Revenue Analysis by Weekday
- Interactive Country Slicer and Cross-filtering

## Key Business Insights
- Total Revenue: £10,642,110.80
- Total Orders: 19,960
- Identified Customers: 4,338
- Average Order Value: £533.17
- Repeat Customers: 2,845
- Repeat Customer Rate: 65.58%

## Dataset
UCI Online Retail Dataset (December 2010 – December 2011).

## Project Objective
To transform raw retail transaction data into meaningful business insights that support sales analysis, customer retention and data-driven decision-making.
